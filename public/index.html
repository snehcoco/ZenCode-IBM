PreVise runs a multi-agent pipeline — built on IBM Bob — that reads a pull request the way four specialists would: one hunting for security holes, one for logic errors, one for missing tests, one for stale documentation. Findings are aggregated, ranked, and can be auto-patched with a re-scan gate before anything ships.

02 — Agents

Each agent owns one failure mode.

Every agent exposes the same contract: scan_file, scan_directory, list[Finding].
agents/sentinel.py

Sentinel

Security scanner — hardcoded secrets, SQL injection, plain-text passwords, weak JWT config, unauthenticated endpoints.

agents/logic.py

Logic

Correctness scanner — missing balance guards, division by zero, implicit None returns, unhandled decode exceptions.

prism/reviewers/test_pilot.py

TestPilot

Coverage scanner — missing test files, assertion-free tests, untested functions, absent edge cases and auth tests.

prism/reviewers/docs_guard.py

DocsGuard

Documentation scanner — broken file references, undocumented or missing routes, absent docstrings.

agents/aggregator.py

Aggregator

Merges every agent's findings, deduplicates by file/line/rule, classifies severity into one ReviewReport.

agents/fix_agent.py

Fix Agent

Applies approved patches keyed by rule ID, then re-scans the touched files to confirm the fix actually landed.
